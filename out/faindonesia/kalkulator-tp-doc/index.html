TP Doc: Cek Kewajiban dan Draf Local File

Cek apakah perusahaan wajib menyusun Master File dan Local File, rapikan daftar transaksi afiliasi, uji kewajaran dengan rentang interkuartil, lalu susun draf Local File yang siap disunting. Dasarnya PMK 172 Tahun 2023.

1. Cek Kewajiban

Angka transaksi memakai nilai tahun pajak sebelumnya. Cukup satu kriteria terpenuhi.

    3. Uji Kewajaran (Rentang Interkuartil)

    Kuartil dihitung seperti QUARTILE.INC di Excel. Penyesuaian ke median bila margin di luar rentang. Pastikan set pembanding Anda sudah lolos seleksi kesebandingan.

    4. Data untuk Draf Local File

    Draf Local File

    Bagian bertanda kuning belum terisi. Draf menyusun kerangka dan angka dari data di atas. Analisis kesebandingan dan dokumen pendukung tetap perlu Anda lengkapi dan review sebelum dipakai.

    Dasar Hitung

    1. PMK 172 Tahun 2023 Pasal 16: kewajiban Master File dan Local File bagi wajib pajak yang melakukan transaksi afiliasi pada tahun berjalan dan memenuhi salah satu kriteria tahun pajak sebelumnya: peredaran bruto lebih dari Rp50 miliar, transaksi afiliasi barang berwujud lebih dari Rp20 miliar, atau masing-masing jasa, bunga, pemanfaatan harta tidak berwujud, dan transaksi afiliasi lainnya lebih dari Rp5 miliar, atau lawan transaksi di negara bertarif PPh lebih rendah dari tarif Pasal 17 UU PPh.
    2. Pasal 18: Master File dan Local File tersedia paling lambat 4 bulan setelah akhir tahun pajak. CbCR tersedia paling lambat 12 bulan setelah akhir tahun pajak, dan hanya wajib bagi entitas induk dengan peredaran bruto konsolidasi paling sedikit Rp11 triliun.
    3. Pasal 34: atas permintaan Direktur Jenderal Pajak, Master File dan Local File disampaikan paling lama 1 bulan sejak permintaan. Ikhtisar kedua dokumen dilampirkan pada SPT Tahunan.
    4. Uji kewajaran memakai rentang interkuartil (kuartil 1 sampai kuartil 3). Margin di luar rentang disesuaikan ke median.

    Aplikasi TP Doc: Cek Kewajiban Transfer Pricing dan Draf Local File

    Transaksi dengan pihak afiliasi harus mengikuti prinsip kewajaran dan kelaziman usaha. Bagi perusahaan yang melewati batas tertentu, itu berarti harus ada dokumen penentuan harga transfer: Master File dan Local File, ditambah CbCR untuk grup yang sangat besar.

    Aplikasi ini menjawab tiga pertanyaan praktis. Wajib atau tidak, dan kapan dokumennya harus tersedia. Berapa nilai transaksi afiliasi per jenis dan mana yang melewati batas. Apakah margin transaksi masih di dalam rentang wajar, dan kerangka Local File apa yang bisa langsung disunting.

    Untuk Siapa

    • Bagian akuntansi dan pajak perusahaan yang punya transaksi dengan induk, anak, atau perusahaan sepengendali.
    • Konsultan pajak dan akuntan yang menyusun kerangka dokumen sebelum masuk ke benchmarking.
    • CFO dan direksi yang ingin tahu paparan kewajiban sebelum akhir tahun.

    Cara Memakai

    1. Isi data tahun pajak sebelumnya di langkah 1 dan baca hasil kewajiban serta tenggatnya.
    2. Masukkan transaksi afiliasi di langkah 2, atau tempel langsung dari Excel.
    3. Isi margin pihak yang diuji dan pembanding di langkah 3 untuk melihat rentang interkuartil.
    4. Lengkapi data di langkah 4. Draf Local File terisi otomatis dan bisa diunduh sebagai Word.

    Pertanyaan Umum

    Siapa yang wajib menyusun Master File dan Local File?

    Wajib pajak yang melakukan transaksi afiliasi pada tahun berjalan dan memenuhi salah satu kriteria tahun pajak sebelumnya: peredaran bruto lebih dari Rp50 miliar, transaksi afiliasi barang berwujud lebih dari Rp20 miliar, atau jasa, bunga, harta tidak berwujud, dan transaksi lainnya masing-masing lebih dari Rp5 miliar, atau transaksi dengan afiliasi di negara bertarif PPh lebih rendah.

    Kapan Local File harus tersedia?

    Paling lambat 4 bulan setelah akhir tahun pajak, yaitu 30 April untuk tahun buku Januari sampai Desember. Bila Direktur Jenderal Pajak meminta, dokumen disampaikan paling lama 1 bulan sejak permintaan.

    Apakah draf ini langsung bisa dipakai?

    Draf menyusun kerangka dan angka dari data yang Anda isi. Analisis kesebandingan, set pembanding, dan dokumen pendukung perlu dilengkapi dan direview sebelum dipakai.
