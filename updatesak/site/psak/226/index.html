PSAK 226 Akuntansi dan Pelaporan Program Manfaat Purnakarya

Berlaku untuk laporan keuangan program manfaat purnakarya (dana pensiun) sebagai entitas pelapor tersendiri.

Inti Pengaturan

01Program iuran pasti melaporkan aset neto tersedia untuk manfaat
02Program manfaat pasti mengungkapkan nilai kini aktuarial manfaat yang dijanjikan
03Investasi program diukur pada nilai wajar
04Pengungkapan kebijakan pendanaan

Contoh Kalimat Kebijakan Akuntansi di CALK

Tanya Jawab

Apa yang diatur PSAK 226?

Berlaku untuk laporan keuangan program manfaat purnakarya (dana pensiun) sebagai entitas pelapor tersendiri.

PSAK 226 dulu nomor berapa?

PSAK 226 dulunya PSAK 18. Penomoran 3 digit berlaku sejak 1 Januari 2024. Padanan internasionalnya IAS 26.

Apa temuan auditor yang sering terkait PSAK 226?

Investasi dana pensiun tidak dinilai wajar; Nilai kini aktuarial tidak mutakhir; Kebijakan pendanaan tidak diungkapkan.

Butuh Pendampingan Penerapan PSAK 226?Tim akuntan bersertifikat CA dan CPA, terbiasa dengan prosedur auditor Big 4.
